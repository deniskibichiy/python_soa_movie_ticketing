# python_soa_movie_ticketing
A modern Python implementation of a service-oriented movie ticket
booking application.

## Services

- Movies Service: Movie catalogue and availability.
- Ticketing Service: Booking management and orchestration.
- Banking Service: Simulated payment processing.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker Compose
- Pytest

## Architecture

The application consists of three independently deployable services
that communicate through HTTP APIs.
